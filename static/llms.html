Japanese-print cards

24 Japanese trading card games, ~3,600 sets, 365K+ cards, refreshed daily (live counts on GET / → panels.japanese). 167,137 of them carry a two-sided dealer quote — an asking price and a buyback bid — which no English-language feed publishes. Per-card lookup at /jp/card/{game}/{set_code}/{card_id}. card_id is unique only within a set, so set_code is required; omitting it resolves to the wrong card.

Read the bid as a reference rate, not an offer. It is one Japanese retailer's quote, settled domestically in yen — you cannot transact at it. There is no resting size or queue behind either number, so it is not an order book. Lookup only: there is deliberately no bulk listing route for this data.
